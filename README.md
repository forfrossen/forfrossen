## ℹ️ About Me

I spent 14 years working in IT system administration before transitioning into professional frontend engineering.

These days, I'm especially interested in building clean, maintainable applications and growing into better architecture practices. Right now, I'm learning more about hexagonal architecture and domain-driven design with NestJS through several ongoing projects — including an intentionally overengineered baby monitor with comfort breach detection, notifications, motion detection, a media library, talk-back functionality, and AD/LDAP login via Authelia — while working across the full system, from backend architecture and infrastructure to night-vision camera integration, microservice-based setups on Raspberry Pi and Proxmox LXC, and full CI/CD pipelines with code quality checks and end-to-end testing using Playwright.

Outside of that, I love diving into whatever sparks my curiosity — whether that's building a 6-DoF robot arm with C++ and ESP-IDF, creating a family-friendly AI assistant with voice cloning and self-hosted service integrations, developing a pgvector-based RAG knowledge server for coding agents, or designing a fully automated, agent-based infrastructure-as-code request fulfillment system.
